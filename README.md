# Description:

This project is the result of the Nasa [Space App Challenge 2026](https://www.spaceappschallenge.org/2026/challenges/the-earth-information-jukebox/?tab=details)

Our team created this project with the idea to offer a new way to fell statistics in a funny way, or even a little bit vively.
### How to install:

```sh
git clone https://github.com/Leo6659/Nasa_space_app_jukebok.git
```

### Dependency:
This program uses "uv" as a dependency manager.
You can install uv with the guide here: [uv installation](https://docs.astral.sh/uv/getting-started/installation/)

You can update dependencies with `uv sync`

Here is how you launch the program.
```sh
uv run src/nasa_space_app_jukebok/__init__.py
```
